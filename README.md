# Contadeus — Revisor Tributario

App web para revisar impuestos de clientes peruanos.
Compara extractos SUNAT con reportes Google Sheets.

## Para actualizar la app
1. Abre app.py en GitHub
2. Haz el cambio
3. Guarda — Streamlit Cloud actualiza automáticamente en 1 minuto

## Cambios frecuentes
- Nueva UIT: buscar `UIT_POR_ANIO` → agregar nuevo año
- Nuevo cronograma SUNAT: buscar `CRONOGRAMA` → agregar nuevo año
- Nuevo tributo: buscar `NOMBRE_TRIBUTO` → agregar código y nombre
